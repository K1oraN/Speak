# Contratos JSON v1

Arquivos UTF-8, objeto JSON sem cercas Markdown, no máximo 256 KiB. A versão `schema_version` deve ser o número 1. IDs de roteiro e sessão são UUIDs; IDs das etapas são strings únicas dentro de cada roteiro. Níveis A1 a C2 são escolhas de dificuldade, não certificações. O esquema de roteiro exige todos os campos listados no pedido; traduções e pronúncias podem ser strings vazias quando desconhecidas. Alternativas são uma lista de respostas naturais. O esquema de relatório exige seis métricas, cada qual número de 0 a 100 ou `null`. Se uma métrica não estiver disponível, envie `null` explicitamente; omissão de campo obrigatório é erro de contrato, nunca zero. `script_id` é `null` no modo livre. `evidence` contém `assessed_turns`, `total_turns`, `acoustic_evidence` e `notes`. `assessment_source` deve ser `chatgpt_self_reported`. `completed` indica conclusão declarada do roteiro/conversa; relatórios parciais devem trazer limitações.

O contrato executável está em `src/core/contracts.ts`. SQL aplica validações de propriedade, estrutura, tipos, intervalos e duplicidade; não é uma implementação integral de todas as restrições Zod de chaves extras e comprimentos. A UI usa Zod antes de chamar RPC. `reports.original` preserva o texto exato; `payload` é JSONB para consulta. O UUID do exemplo de relatório é fictício: substitua pelos dados reais da sessão (não importe o modelo como se fosse nota). Os exemplos de restaurante são material didático, não sessões. Pronúncias aproximadas não representam análise fonética; se faltar uma pronúncia confiável, o campo fica vazio.

## Rubrica do tutor

0–39 dificuldade grave; 40–59 limitado; 60–79 adequado com lacunas; 80–100 consistente para o nível solicitado. Use `null` sem evidência suficiente. Gramática: estruturas observadas. Vocabulário: variedade e adequação no contexto. Compreensão: inferida a partir das respostas, não teste auditivo isolado. Contexto: adequação à situação comunicativa. Fluidez percebida: julgamento qualitativo, não medida temporal. Pronúncia: `null` se não houve evidência acústica apropriada. Nota geral é atribuída pelo tutor somente quando justificável; o SpeakUp não recalcula nota pedagógica. Não inclua falas de explicação, perguntas em português de ajuda ou respostas inventadas como evidência. Declare cobertura. O sistema valida estrutura, não verifica se os fatos declarados pelo tutor são verdadeiros.
