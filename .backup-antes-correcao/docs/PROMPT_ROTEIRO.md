# Prompt para criação de roteiro

Crie um roteiro SpeakUp v1 para [IDIOMA], nível [A1–C2], cenário [CENÁRIO], objetivo [OBJETIVO]. Retorne apenas um objeto JSON válido em UTF-8, sem Markdown. Use schema_version=1 e um UUID válido e novo em script_id. Inclua language, level, scenario, title, description, estimated_minutes (inteiro de 1 a 240), steps (1 a 100), tutor_instructions. Cada etapa precisa de id único, context (em português), tutor_text, tutor_translation_pt, tutor_pronunciation_pt, student_suggestion, student_translation_pt, student_pronunciation_pt, alternatives (array de strings). Use falas naturais e alternativas equivalentes, uma pergunta por etapa. Pronúncias escritas são aproximações para brasileiros, não IPA ou medições; deixe vazio se não for confiável. Não produza avaliação ou XP. Use os exemplos em examples/ como referência estrutural.
